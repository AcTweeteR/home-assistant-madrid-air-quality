# Madrid Air Quality

Home Assistant custom integration for official air-quality and meteorological monitoring stations operated by the Comunidad de Madrid, Spain.

**Español:** Integración personalizada para Home Assistant que permite incorporar las estaciones oficiales de calidad del aire y sus datos meteorológicos de la Comunidad de Madrid.

> This is an independent community project and is not affiliated with or endorsed by the Comunidad de Madrid.

## Status

Initial development. The integration is being built for graphical configuration, multiple station selection and HACS distribution.

## Planned features

- Official Comunidad de Madrid data sources
- Multiple monitoring stations
- Air-quality pollutants and meteorological observations when available
- Native Home Assistant devices and sensors
- UI configuration — no YAML required
- Spanish and English translations
- HACS installation
